# 0.6.0 — 个人中心与平台 API Keys 管理

状态：2026-09-17 完成本地发布准备，尚未合并、打包或部署。功能源提交为 `37126c6`，发布构建须使用包含本次版本准备的最终提交。

## 变更范围

- 新增 `/profile`，包含基本资料、账号安全、API Keys、我的用量组、我的用量。允许修改本人显示名称，组织、邮箱和角色由管理员维护。
- 移除“我的接入”菜单；旧 `/my-access` 仍可直接访问，不自动跳转。API Keys 位于个人中心，不新增独立侧栏菜单。
- API Keys 默认本人视图，管理员显式切换到当前组织管理；普通成员仅查看、撤销本人 Key。搜索、状态/员工/组筛选、分页、详情与日志跳转复用既有授权范围。
- 历史组筛选独立于当前列表页；创建 Key 仍只选择员工有效成员组。完整 Key 仅创建时显示一次，关闭或离开页面后清空。
- 个人组保留停用、归档状态，模型预览使用现有组权限；个人用量对管理员同样强制限定本人和当前组织，并保留人民币成本、估算成本与待核对提示。
- 密码修改复用既有接口与会话失效规则；不新增账号激活、首次设密或密码找回流程。未设置密码的员工仍由管理员管理 Key。

## 升级兼容性

相对 0.5.1，无数据库 schema、迁移、依赖、预算结算或网关协议变更；不重新签发现有 Key，不自动变更模型权限或员工 Key 功能开关。上游渠道密钥仍在渠道管理。

身份读取接口增加安全展示字段；新增本人资料更新、本人组/模型/用量读取、当前组织 Key 集中查询。既有 Key 列表保持原分页字段并追加关系摘要；本人/指定员工列表追加仅含组 ID 与名称的历史筛选选项。

版本号已同步到 `package.json`、`package-lock.json`、`conf/.env.example` 和部署镜像加载示例。未修改实际 `.env` 或生产配置。
