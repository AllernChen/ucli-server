# 0.5.0 — 内部采购成本与运营管理

## 变更范围

- 使用日志：员工、用量组、渠道、模型等组合筛选，安全的历史价格与费用明细，筛选结果 CSV 导出。
- 统计分析：按请求与渠道分摊分别汇总，缓存用量、人民币采购成本、员工和用量组分析，支持明细下钻。
- 用量组：预算风险筛选、成员与 Key 管理信息、预占和结算明细，以及完整分析入口。
- 服务总览：真实服务健康、成本和用量摘要、异常渠道及预算风险提示；遵循现有角色权限。
- 相比已部署 0.4.1（`2eb0b4a`），无数据库 schema、迁移或依赖变化，不调整采购价格、历史费用、预算或模型权限。

## 发布约束

用户已授权发布 0.5.0，并仅将生产 `conf/.env` 的 `VERSION=0.4.1` 改为 `VERSION=0.5.0`。其他字节及全部密钥保持不变，通过逆变换整文件哈希校验。

从干净、已提交的源码构建版本化镜像，交付包不包含生产配置、密钥或数据库备份。升级前保留 0.4.1 镜像及文件，创建新鲜数据库备份并验证隔离恢复，核对 16 条既有迁移及其内容未变。使用 `./install.sh update`，部署后核对镜像 ID、迁移状态、健康和页面。

已合并功能的本地验证见 [验证记录](verification/2026-09-15-admin-cost-operations.md)。发布版本的最终验证与生产结果将在实际执行后补录；当前文档不代表部署完成。
