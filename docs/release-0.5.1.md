# 0.5.1 — 管理端视觉与响应式修复

## 变更范围

- 统一原生按钮、链接和文本域的深色主题及键盘焦点样式。
- 900 像素以下使用顶部多列导航，宽表格在自身容器内横向滚动。
- 调整趋势图图例、绘图区和横轴标签，避免内容重叠。
- 相比已部署 0.5.0（`60e0222`），无服务端接口、数据库 schema、迁移或依赖变化。

## 发布约束

生产 `conf/.env` 仅允许将 `VERSION=0.5.0` 更新为 `VERSION=0.5.1`，其他配置及密钥保持不变并校验。交付包不包含 `.env`、凭据或数据库备份。

升级前保留 0.5.0 镜像及文件并创建新鲜数据库备份。使用 `./install.sh update`，部署后核对镜像 ID、迁移状态、四个容器、两个健康端点和管理端页面。

实现与本地浏览器验收见 [管理端视觉修复验收记录](verification/2026-09-16-admin-visual-fixes.md)。发布源提交、离线包和生产验收结果由本次发布归档记录保存。
