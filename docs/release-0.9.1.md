# 0.9.1 — 组织预算可视化、个人 Key 查看与 Key 覆盖

状态：2026-09-20 代码与验证完成，待构建发布件并部署公司服务器。

## 变更范围

- 组织管理列表新增「预算进度」。
- 组织概述新增项目预算汇总和近 30 天用量汇总。
- 项目概述新增预算进度、人员情况、负责人和有效项目 Key 汇总。
- 个人中心可查看本人全部项目 Key。
- 个人 Key 明文查看需输入当前登录密码；接口仅限网页会话、仅限本人、响应不落缓存并写入审计。
- 新增组织项目成员 / Key 覆盖补齐脚本，支持 dry-run、apply 和幂等复查。
- 新增员工网页初始密码引导脚本，可为无密码账号生成随机密码并强制首次登录改密。
