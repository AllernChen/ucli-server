# ADR-0001：独立实现模型网关

## 决策

UCLI Server 的模型网关使用 TypeScript/NestJS 独立实现。公开的 New API 项目只用于了解行业通用能力和公开行为，不作为源码、运行时、容器镜像、依赖、数据库或测试基线。

## 原因

项目交付策略不能接受 AGPLv3 及其附加署名义务。仓库不得复制 New API 的代码、数据结构、接口文案或前端资产。渠道、权重、失败切换、预结算和使用日志均根据 UCLI 自身需求重新设计。

## 验证

- `package-lock.json` 和容器镜像不得包含 New API 或 One API 派生包。
- 发布前执行依赖许可证扫描。
- 协议测试使用公开协议测试向量和自建 Mock Provider。
