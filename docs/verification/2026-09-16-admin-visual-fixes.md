- 原生按钮、链接、文本域与焦点状态在深色背景中可读。
- 900 像素以下侧栏切换为顶部多列导航，页面没有横向溢出。
- 用量组和统计明细表在自身容器内横向滚动，列内容不再挤成逐字换行。
- 趋势图图例与绘图区分离，横轴自动隐藏重叠标签。
- 用量组创建抽屉在窄屏下可操作；验收后取消，没有创建测试数据。
