# 0.6.0 个人中心本地验收

日期：2026-09-17。基线：`origin/main` 的 `13048b0`，包含 `v0.5.1`（`6748455`）。实施分支：`codex/personal-center-0.6.0`。本记录是功能验收，不是发布或生产部署记录。

## 完成范围

- 移除“我的接入”菜单，旧 `/my-access` 保留直接访问，无自动跳转。
- 新增 `/profile`，包含基本资料、账号安全、API Keys、我的用量组、我的用量；不新增独立 API Keys 菜单。
- 显示名称由本人修改并审计；邮箱、组织、角色保持只读。密码修改复用既有接口，成功后退出当前登录。
- API Keys 默认本人视图；管理员显式切换到当前组织管理，成员仅查看与撤销本人 Key。复用原创建、编辑、启停、撤销、删除流程。
- 提供服务端搜索、状态/员工/组筛选、分页、详情和日志链接；历史组筛选不依赖当前列表页，创建仍只使用有效成员组。
- 完整 Key 仅创建时显示，离开或关闭后清空；接入说明由新旧页面复用。
- 个人组保留停用/归档状态；模型预览复用现有权限。个人用量即使由管理员访问，也强制限定本人和当前组织。
- 无新增依赖、数据库迁移、预算结算或网关协议变更；版本号仍为 0.5.1，留待发布准备统一更新。

## 浏览器与真实 HTTP 验收

浏览器实际检查：

- 管理员登录个人中心，修改显示名称后侧边栏及身份摘要更新。
- 管理员默认仅显示本人 Key，切换组织模式后显示组织员工 Key；创建抽屉可选员工和对应组，取消正常。
- 普通成员无组织管理、创建、编辑、启停和删除入口，能看到本人的可用及已撤销 Key。
- 用 Enter 打开 Key 详情，展示员工、组、创建人和生命周期日期；日志链接携带账号、组织和 Key 范围。
- 我的用量组显示正常与停用状态，停用组不能预览模型；有效组的空模型目录正常展示。
- 我的用量显示合成的 1 次请求、120 Token、人民币成本及估算成本 0.10000000。
- 旧 `/my-access` 加载后仍停留原地址且可访问，侧边栏没有旧菜单或独立 API Keys 入口。
- 390×844 视口下个人资料与 Key 页无整页横向溢出；验收后恢复视口。控制台未记录警告或错误。

另以真实 HTTP 调用验证：匿名拒绝、资料额外字段拒绝、成员不能查询组织 Key 或冒用他人账号、Key 不能访问管理身份接口、个人组无预算字段；管理员个人用量查询即使带他人参数仍只有本人数据，并与同范围日志条数和成本一致；Key 创建仅返回一次明文、列表无摘要哈希、本人撤销成功、撤销后不能恢复。

密码提交、单次明文关闭/切换清理、完整生命周期、请求失败重试及过期请求隔离由组件与后端自动化覆盖；未在浏览器实际提交密码或签发/撤销 Key。最后一轮历史组跨页筛选由自动化用例覆盖。
