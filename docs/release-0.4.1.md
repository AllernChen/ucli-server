# 0.4.1 — DeepSeek 缓存兼容与成本核算

## 变更范围

- 组预算允许官方 DeepSeek Anthropic 端点的合法文本/工具缓存标记原样透传，要求全部候选渠道满足条件；不按渠道名称判断，不开放其他供应商的缓存写入计费。
- 共享用量解析支持 DeepSeek `prompt_cache_hit_tokens`，标准字段（含零值）优先；总输入不重复累加缓存命中。
- 预占仍保守估计，结算按上游用量和请求时人民币价格快照；未知缓存写入成本保留待核对。
- 相对生产 0.4.0，无数据库 schema、迁移或依赖版本变更。公司价格配置和历史费用不随发布改写。

## 发布要求

本地完整 `npm run verify` 与 HTTP 集成检查通过后，才从已提交的干净 main 打包。发布包记录精确提交和镜像 ID，不含 `.env`、密钥或数据库备份。

生产仅允许 `conf/.env` 的 `VERSION=0.4.0` 改为 `VERSION=0.4.1`；通过逆变换哈希证明其他字节不变。升级前保留旧镜像、发布文件和新鲜数据库备份，并在隔离 PostgreSQL 验证恢复；使用 `./install.sh update`，核对 16 条既有迁移校验值未变。

真实验收使用独立授权的短期 Key，不复用或导出现有 Key，不调整组预算。对比上游响应 usage、平台使用日志和请求预算账目；这些证据不等于厂商最终账单。
